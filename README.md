# Teller County STR Help

A Vercel-ready Next.js starter site for `tellercountystrhelp.com`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Put this folder in a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Vercel should detect Next.js automatically. Click **Deploy**.
5. In the Vercel project, open **Settings → Domains** and add `tellercountstrhelp.com`.
6. Update the domain DNS records exactly as Vercel instructs.
